🤖 Use AI to Learn AI

These free tools should be your study companions — ask them questions, get code explained, debug errors, and request examples in Marathi or Hindi.

💬 Claude (Anthropic)
Paste any code or error and ask "explain this simply." Available at claude.ai — free tier available.
💬 ChatGPT
Ask "give me a beginner Python exercise on lists." Can explain in Hindi or Marathi if you ask. Free at chatgpt.com.
🔍 Perplexity AI
Like Google but gives clear direct answers. Great for looking up "what is a pandas DataFrame" with sources.
💻 GitHub Copilot
Free for individuals. Suggests code as you type inside VS Code editor. Like autocomplete, but for entire programs.

📅 Suggested Week-by-Week Plan

Week 1
Python Setup + Basics
Install Python, open Google Colab, learn variables, print(), if-else. Do Programiz first 5 lessons.
Week 2
Python Logic + Loops
Learn for/while loops, lists, functions. Watch Code With Harry or freeCodeCamp up to hour 2.
Week 3
First Mini-Project
Build a simple calculator or quiz in Python. Use Claude/ChatGPT if stuck. Celebrate finishing!
Weeks 4–5
Data: Pandas & Spreadsheets
Kaggle Learn: Python + Intro to Pandas. Learn to read CSV files and analyse data like Excel but with Python.
Week 6
Data Visualisation
Kaggle: Data Visualisation course. Make graphs and charts from data using Matplotlib & Seaborn.
Weeks 7–8
Understanding AI
Elements of AI course + 3Blue1Brown neural network series. No coding — just building mental models of how AI works.
Weeks 9–10
First AI Model
fast.ai Lesson 1 — train an image classifier. Use Google Colab. You will have a working AI by end of week 10!
Beyond
Deepen & Specialise
Google ML Crash Course, Kaggle competitions, build personal projects. The learning never stops — but now you have the foundation.

✅ Daily Habits That Work

  • 30–60 minutes daily beats 4 hours on weekends
  • Always type code yourself — never just read it
  • When stuck, ask Claude or ChatGPT immediately
  • Keep a notebook of "things I learned today"
  • Celebrate small wins — finishing a chapter matters

❌ Common Mistakes to Avoid

  • Don't try to memorise syntax — look it up freely
  • Don't skip exercises, even easy ones
  • Don't buy courses until you've used all the free ones
  • Don't get stuck alone for more than 10 minutes — ask AI
  • Don't compare your pace to others online
